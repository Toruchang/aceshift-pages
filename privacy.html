에이스교대(AceShift Calendar) 개인정보 처리방침

최초 시행일: 2026-10-01 · 최종 변경일 및 현재 방침 시행일: 2026-10-02

이 방침은 iPhone 앱 「에이스교대」(영문명 AceShift Calendar, 이하 “앱”)가 이용자의 정보를 어떻게 다루는지 설명합니다.

1. 기기에 저장되는 정보

앱은 회원가입이나 로그인 없이 동작하며, 이용자가 입력한 정보는 기본적으로 이용자의 기기 안에만 저장됩니다(Local First). 앱은 이 정보를 별도의 계정 서버나 클라우드에 올리거나 동기화하지 않습니다.

기기에 저장될 수 있는 정보는 다음과 같습니다.

  • 교대근무 형태와 근무일정, 입사일 등 근무 기준 정보
  • 실제 근무 시간, 근무 변경 기록
  • 근태(연차, 반차, 교육 등)와 O/T(초과근무) 정보
  • 교대표의 근무자 정보(이름, 직책, 연락처 등 이용자가 직접 입력한 내용)와 동료 근태
  • 급여 계산 설정, 수당·지급 항목, 예상 급여 계산 결과
  • 세금 및 공제 설정
  • 근무 알람 설정
  • 할일, 할일 알림 설정
  • 날짜 메모
  • 앱 설정

앱에 표시되는 급여·세금·공제 금액은 이용자가 입력한 설정을 기준으로 기기에서 계산한 예상값입니다.

2. 공휴일 정보 조회(외부 통신)

앱은 최신 공휴일 정보를 받기 위해 공휴일 API(https://taeyunicloud.synology.me/api/v1/public-holidays)에 요청을 보냅니다. 이 요청에 담기는 정보는 다음뿐입니다.

  • 조회하려는 연도
  • 이미 받은 공휴일 정보가 최신인지 확인하기 위한 HTTP 캐시 확인 정보(ETag / If-None-Match)
  • 인터넷 통신에 필요한 표준 HTTP 요청 정보

이용자의 근무, 급여, 근태, 할일, 메모 등 앱에 저장된 정보는 공휴일 API로 전송하지 않습니다. 공휴일 정보를 받지 못하는 경우에는 앱에 포함된 기본 공휴일 자료를 사용합니다.

이 밖에 앱이 이용자 정보를 외부로 전송하는 기능은 없으며, 이용자 정보를 저장하는 계정 서버나 클라우드 동기화도 없습니다.

3. 공휴일 API 서버의 기록

정상 요청의 HTTP 접속 기록(Access Log)

현재 공휴일 API 운영 환경에서는 정상적인 공휴일 조회 요청에 대해 nginx HTTP 접속 기록(Access Log)을 생성하지 않습니다. 따라서 정상 공휴일 조회 요청의 다음 정보를 HTTP 접속 기록으로 계속 저장하지 않습니다.

  • 접속한 기기의 IP 주소(Client IP)
  • User-Agent
  • 요청 경로 및 조회 조건(Request Path / Query)
  • 요청 헤더(Request Header)
  • 요청 시각(Request Timestamp)
  • 요청 식별번호(Request ID)

서비스 운영·장애 기록

위 접속 기록과는 별도로, 공휴일 서비스와 서버의 장애 진단 및 정기 갱신 작업(Scheduler) 운영을 위해 최소한의 운영 정보가 기록될 수 있습니다. 예를 들면 실행 시각, 대상 연도, 성공·실패 여부, 공휴일 개수입니다. 이 운영 기록은 서비스 유지를 위한 것이며, 이용자 프로파일링, 광고, 추적 목적으로 사용하지 않습니다.

서버 보안 기능의 기록

공휴일 API가 운영되는 서버(Synology DSM)의 자체 보안 기능은 공격 차단, 비정상 접근 탐지 등 시스템 보안을 위해 보안 이벤트와 관련 IP 정보를 기록할 수 있습니다. 이는 시스템 보호를 위한 기록으로, 위에서 설명한 정상 공휴일 조회 요청의 HTTP 접속 기록과는 별개입니다.

4. 광고, 분석, 추적

  • 앱은 광고를 표시하지 않습니다.
  • 앱은 이용 통계를 수집하는 분석(Analytics) 도구를 사용하지 않습니다.
  • 앱은 다른 회사의 앱이나 웹사이트에 걸쳐 이용자를 추적(Tracking)하지 않습니다.
  • 앱에는 제3자 광고 또는 분석 SDK가 포함되어 있지 않습니다.
  • 이용자 정보를 바탕으로 한 프로파일링을 하지 않습니다.

5. 알림 및 알람 권한

이용자가 근무 알람이나 할일 알림을 사용하도록 선택한 경우, 앱은 해당 기능을 제공하기 위해 iOS 알림·알람 권한을 요청할 수 있습니다. 권한은 iPhone의 설정 앱에서 언제든지 변경할 수 있으며, 권한을 허용하지 않으면 해당 알림 기능이 제한될 수 있습니다. 근무 알람과 할일 알림은 iPhone의 알림·알람 기능으로 기기에서 예약되며, 별도의 원격 푸시(Push) 서버를 사용하지 않습니다.

6. 정보 삭제

앱의 앱 설정 > 앱 내 정보 삭제 기능으로 앱에 저장된 이용자 정보를 삭제할 수 있습니다. 이때 근무, 급여, 근태, 알람, 할일, 메모 등 이용자 데이터와 함께, 공휴일 API에서 받아 기기에 보관하던 공휴일 정보도 삭제됩니다. 앱에 기본으로 포함된 공휴일 자료는 앱 자체의 구성 요소이며 이용자 개인정보가 아니므로 삭제 대상이 아니고 그대로 유지됩니다.

앱을 기기에서 삭제해도 앱에 저장된 정보가 함께 삭제됩니다. 삭제된 정보는 복구할 수 없습니다.
